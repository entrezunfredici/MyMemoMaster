# Audit RGAA 4.1.2 — les 106 critères

**Statut** : **EN COURS** — audit ouvert le 2026-08-30, à poursuivre sur plusieurs sessions. Ce document est un journal de travail resumable, pas un livrable final : tant que la ligne « État global » ci-dessous n'affiche pas 106/106 verdicts posés, aucun taux de conformité ne doit être cité comme définitif.

**Référentiel** : [RGAA 4.1.2](https://accessibilite.numerique.gouv.fr/doc/RGAA-v4.1.2.pdf), téléchargé et extrait en texte le 2026-08-30 (`pdftotext -layout -enc UTF-8`) — **pas** reconstitué de mémoire ni depuis un résumé web (une première tentative via récupération web s'est révélée tronquée et partiellement inexacte sur les thématiques 10 à 13 ; écartée). 106 critères confirmés en recomptant les intitulés extraits du PDF officiel : 9+2+3+13+8+2+5+10+4+14+13+11+12 = 106.

**Méthode** : pour chaque critère, verdict **C** (conforme) / **NC** (non conforme) / **NA** (non applicable — le type de contenu visé n'existe pas dans l'app), avec la preuve qui le fonde (fichier, ligne, résultat de commande, ou page de l'échantillon inspectée en direct). Un audit RGAA en bonne et due forme demande de tester chaque critère sur un **échantillon de pages**, pas seulement de lire le code — voir §2. Les verdicts posés à partir d'une recherche exhaustive dans tout `src/` (ex. « aucun `<video>` dans le dépôt ») sont aussi solides qu'un test par page et sont marqués comme tels.
